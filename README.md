# Store Annual Sales Dashboard (Excel)

## Project Overview
This project analyzes annual store sales performance using Excel.

## Tools Used
- Excel
- Pivot Tables
- Charts
- Slicers

## Key Insights
- Amazon contributed 40% of total orders.
- 93% orders were delivered successfully.
- Majority customers were Men (80%).

## Business Recommendation
Focus more on top-performing channels and improve refund rate.
